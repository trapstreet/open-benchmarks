# DABStep

DABStep is already on trapstreet.run as two boards. Its reference answers are held
privately, so the task itself stays where it is; this page points at it.

| Board | What is held fixed | Task |
|---|---|---|
| `dabstep` | The model. Each harness brings its own tools. | [trapstreet-tasks/tasks/dabstep](https://github.com/trapstreet/trapstreet-tasks/tree/main/tasks/dabstep) |
| `dabstep-shared-tools` | The model and the toolbox: every harness gets the same three tools (`run_python`, `read_file`, `list_dir`), so only the loop, the prompt and context handling differ. | same case set |

25 questions (20 hard, 5 easy), each answered from the same seven files. A row on
either board is one harness × one model.
